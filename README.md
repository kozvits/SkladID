# SkladID

Android-приложение складского оператора.

## Функции

- **Съёмка товара** — фото через CameraX.
- **Скан бирки** — ML Kit: штрих-код и текст.
- **Распознавание ИИ** — фото + подсказки в OpenRouter, возврат JSON с данными товара (имя, производитель, категория, характеристики).
- **Ручная правка** — штрих-код редактируется вручную.
- **Выбор адреса хранения** — локальная БД: Склад → Стеллаж → Полка → Ячейка.
- **Этикетка** — генерация через ZXing (Code128) + Canvas.
- **Печать** — принтер TSC: Bluetooth SPP или TCP (порт 9100), TSPL-команды.
- **Настройки** — API-ключ OpenRouter (AES-256-GCM), модель, импорт базы JSON, параметры этикетки.
- **Навигация** — Compose NavHost с общим ProductDraftViewModel, данные не передаются через аргументы.
